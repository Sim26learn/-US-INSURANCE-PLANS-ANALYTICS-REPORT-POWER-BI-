    # US Insurance Plans Analytics Report (Power BI)

## Overview
This project was developed in **Power BI Desktop** to analyze insurance company and plan data across states and ownership types. The focus was on data preparation, modeling, KPI development, visualization, and delivering actionable insights for healthcare policy and provider relations.

## Key Highlights
- **Data Preparation & Modeling**  
  Imported and cleaned insurance company and plan datasets, built relationships between tables (companies, plans, states, ownership).  
  *(Skills: Power Query, Data Modeling)*

- **KPI Development**  
  Created measures for average premium, average MOOP (maximum out-of-pocket), total deductible, and plan counts.  
  *(Skills: DAX, KPI Design)*

- **Visualization & Insights**  
  Designed interactive visuals including bar charts, pie charts, and maps to compare premiums, deductibles, and ownership (Government vs Private) across insurers and states.  
  *(Skills: Power BI Visualization, Report Design)*

- **Business Impact**  
  Delivered insights into cost distribution, ownership patterns, and regional presence of insurers, supporting healthcare policy and provider relations analysis.  
  *(Skills: Data Storytelling, Healthcare Analytics)*

## Scope
- **Included**: Data cleaning, modeling, DAX measures, and report creation in Power BI Desktop.  
- **Not included**: Power BI Service features (publishing, dashboards, alerts, deployment).
